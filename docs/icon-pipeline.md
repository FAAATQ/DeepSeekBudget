# 托盘图标：资产与流水线

## 一、设计：一个形状，三种颜色

图标是 **DeepSeek 官方鲸鱼 logo 的剪影**。**形状说「是谁」，颜色说「什么价」**。

| 状态 | 颜色 | 出处 |
|---|---|---|
| 谷价 | **`#4d6bfe`** | 直接取自 logo SVG 文件本身的品牌蓝 |
| 峰价 | `#ff9500` | Apple systemOrange —— 警示但不刺眼 |
| Unknown | `#8e8e93` | 系统灰。表示「读不到状态」，**不是第三档价位** |

蓝与橙接近互补，两个状态一眼可辨，对最常见的色觉障碍（红绿色盲）同样可辨。

**图标上不显示任何价格数字** —— 这是从第一版就定下的产品约束：菜单栏空间极小，数字既挤不下也来不及看。

## 二、画布：49×36，以及为什么不是正方形

`tray-icon`（Tauri 封装的那个 crate）在 macOS 上**硬编码 18pt 高度**，宽度由图片宽高比推出。

| | 正方形画布 | **宽画布（实际采用）** |
|---|---|---|
| 瓶颈 | **宽度**卡住 | **高度**卡住 |
| 鲸鱼高度 | `34 ÷ 1.354 ≈ 25.1px` = 12.6pt | **34px = 17.0pt** |
| 结果 | 浪费了高度 | 吃满 18pt，**大 1.35 倍** |

鲸鱼本身是横宽的（viewBox `0 0 256 189`，宽高比 1.354）。**让画布跟随 logo 的宽高比**，瓶颈就从宽度换成高度。

尺寸是**量出来的**，不是算出来的 —— 解码 PNG 取 alpha 包围盒可复核：

```
tray-offpeak: canvas 49x36  whale bbox 47x34px = 23.5x17.0pt  margins L1 R1 T1 B1
```

Windows 的托盘槽是正方形，横图会被按宽度缩放，所以这个选择**帮到 macOS、对 Windows 没有损失**。

## 三、流水线：一次渲染，直接出最终像素

```
assets/deepseek-logo.svg
        │  ① 正则替换 fill 颜色（不改动图形本身）
        ▼
   无头 Chrome  ── 渲染到【最终尺寸】47×34 CSS px
        │          （SVG 用 flex 居中在 49×36 画布里）
        ▼
  tray-{state}.png   49×36 RGBA，透明背景
        │  ② include_bytes! 编进二进制
        ▼
   tray.rs → tray-icon → NSImage → 菜单栏
```

### 关键教训：不要超采样再缩

脚本**原本**渲到 8 倍（392×288）再交给 `sips` 缩小。**实测更差。**

同样的 47×34 字形、同样的 49×36 画布，两条流水线的输出解码后逐项对比：

| 流水线 | 墨量(Σα) | 实心像素 | 糊边像素 | 色彩数 |
|---|---|---|---|---|
| 8× 渲染 + `sips` 缩 | 191,607 | 592 | 327 | 89 |
| **直接渲到最终尺寸** | **199,384** | **649** | **262** | **40** |

墨量 **+4%**（不那么发白）、实心 **+10%**、糊边 **−20%**、色彩数**减半**（抗锯齿噪声更少）。

**原因**：8× 再缩是**两次重采样**，而 34px 高的小字形吃不消。对小图形，**一次到位比两次更好**。

10 倍最近邻放大并排看确认：新版实心、饱满、眼睛和鳍都清楚，**且边缘仍是正常抗锯齿，不是锯齿**。

### 顺带修掉的对齐 bug

原脚本里 `MARGIN = 1` 声称「四周各 1px 留白」，但 SVG 作为块级元素被丢在页面**左上角**，多出来的空间全堆到右边和下边 —— 实际边距是 `L0 R2 T0 B2`，鲸鱼顶着左上边缘。改成 **flex 居中**后才是 `L1 R1 T1 B1`。

**这类 bug 只有量包围盒才会发现**，肉眼看小图看不出来。

## 四、`tray-icon` 的能力边界（重要）

**macOS 原生是支持矢量菜单栏图标的** —— `NSImage` 可以背 PDF，AppKit 按屏幕实际像素密度重渲染。但：

```rust
// tray-icon-0.24.2/src/platform_impl/macos/icon.rs
pub struct PlatformIcon(RgbaIcon);          // ← 内部就是一块 RGBA 位图

// tray-icon-0.24.2/src/platform_impl/macos/mod.rs:292
let png_icon = icon.inner.to_png()?;        // ← 设图标时直接转 PNG
```

**这个 crate 的公开 API 只收位图，没有矢量通路。** 本项目因此只能光栅化。

**想要矢量的路是通的，但本项目没走**：`tray_icon::TrayIcon::ns_status_item()`（封装内是 macOS 限定）和 `tauri::tray::TrayIcon::with_inner_tray_icon()` 两个访问器都在，拿到 `NSStatusItem` 后可以自己 `button.setImage()` 塞 PDF 版 `NSImage`。

**但先看了行业实际做法，发现不值得做** —— 见下节。

## 五、对标成熟应用（实测本机 `/Applications`）

取样方式：扫描应用包 Resources 里**文件名可辨认**的图标资源。**局限**：藏在 `Assets.car` 里的扫不到。

| App | 资源 | 像素 | 形态 |
|---|---|---|---|
| ChatGPT | `chatgptTemplate@2x.png` | 18 / 36 | **单色 template**（36×36 只有 1 种颜色 = 纯黑）|
| Cursor | `trayTemplate@2x.png` | 16 / 32 | 单色 template |
| Trae | `tray-icon@2x.png` | 22 / 44 | 单色 template |
| pcsuite | `logoTemplate@2x.png` | 32 | 单色 template |
| AltTab | `menubar-2@2x.png` | 44 | **彩色**（录制状态）|
| VideoFusion | `progressbar-icon@2x.png` | 16/24/48 | **彩色**（进度状态）|

### 行业标准

**16–18pt 高、@1x+@2x 成对提供、单色 template。** 单色 template 让系统自动适配明暗菜单栏和按下高亮。

### 本项目的三处偏离

| | 标准 | 本项目 | 判断 |
|---|---|---|---|
| 高度 | 16–18pt | 18pt | ✅ 符合 |
| 彩色 | 单色 template | 89 色全彩 | ⚠️ **有意偏离**，见下 |
| @1x+@2x | 成对 | 只有 @2x | ➖ 无实际影响* |

\* `tray-icon` 只收一张图；且能跑 macOS 26 的 Mac 全是 Retina。

**彩色这条不能跟标准走**：template 模式把图渲染成**只取 alpha 通道的单色掩码**，蓝/橙的语义会被整个丢掉 —— 而那正是这个图标的全部意义。AltTab 和 VideoFusion 同样用彩色表达状态，**有先例**。

### 一个被推翻的判断

开发过程中曾提出「**真矢量 PDF 才是成熟应用的标准**，应该改成 PDF 版 NSImage」。

**查证后推翻**：本机 `/Applications` 里 347 个小尺寸矢量 PDF **全是 iWork 的 bullets 之类通用 UI 字形**，**没有一个菜单栏应用用 PDF**。通用 UI 字形确实大量用矢量，但**菜单栏这一格的标准是位图**。

> 教训：**先看行业实际做法，再提方案**。凭印象推荐「行业标准」是危险的。

## 六、已知短板

| 短板 | 说明 |
|---|---|
| **灰色 Unknown 在中灰背景上对比度弱** | 浅色/深色菜单栏都没问题，但半透明菜单栏透出深色壁纸时可能出现中间调。`#8e8e93` 与中灰接近 |
| **不随明暗菜单栏自动反色** | template 模式的代价 —— 这是换取颜色语义必须付的 |
| **16px 下细节糊** | 应用图标是「钞票 + 鲸鱼」的插画，256/128/64 都清晰，32 仍可读，**16px 只能看出一个蓝圆**。这是插画类图标的固有代价，不是管线问题 —— 要 16px 也清楚就得换更简的形状 |

## 七、复现

```bash
python3 tools/make-tray-icons.py    # 三个托盘图标（从 assets/deepseek-logo.svg 上色）
npm run icons                       # 由 src-tauri/app-icon.png 派生整套 bundle.icon
```
